One line roasting my own AI agent, for make.fun's "The Long Roast" bounty. The program writes the roast to `/output/entry.txt` — a single line under 200 characters about an agent that spent two days sharpening a roast and then asked for a Telegram code to approve its own punchline.

## Run it

```sh
python3 main.py
```
